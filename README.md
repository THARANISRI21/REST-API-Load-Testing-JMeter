# REST API Load Testing using Apache JMeter

## Project Overview
This project focuses on performing load testing on a REST API using Apache JMeter.

## Objective
To evaluate the performance and reliability of a REST API under simulated user load.

## Tools Used
- Apache JMeter
- Java JDK

## Load Testing Strategy
The REST API is tested by simulating multiple virtual users and analyzing its performance under load.

## Key Metrics
- Response Time
- Throughput
- Error Rate
- Latency
- Number of Requests

## Test Configuration
- Tool: Apache JMeter
- Test Type: Load Testing
- Simulated Users: 1000 Users
- API Type: REST API

## Success Criteria
- Response time remains acceptable.
- Error rate is minimal.
- API handles the simulated user load.
- System remains stable during testing.

## Results
The results are analyzed using:
- View Results Tree
- Summary Report
- Aggregate Report

## Conclusion
Apache JMeter was used to analyze REST API performance under simulated user load.
